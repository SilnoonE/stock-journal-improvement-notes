## 기록 원칙


- 직접 확인한 사실, 추정 원인, 추가 검증 항목을 구분합니다.
- 실제 금액·원본 횟수·광고 단가 대신 필요한 경우 반올림한 상대 변화만 공개합니다.
- 사용자 정보, 계정·광고 식별자, 비공개 데이터와 핵심 구현은 공개하지 않습니다.
- 분석과 실제 수정·실험 결과를 구분하고, 검증하지 않은 효과를 성과로 쓰지 않습니다.
- 원본 내부 보고서와 운영 데이터는 이 폴더에 업로드하지 않습니다.
