# 주식매매노트 웹사이트 제작 기록 · Y Labs

[공식 홈페이지](https://tradingnote.kr/) · [Android 앱](https://play.google.com/store/apps/details?id=com.thirteenthapp_stockmemo) · 문의: dnfgocks@gmail.com

Android 앱에서 내보낸 백업을 PC에서도 돌아볼 수 있도록 공식 홈페이지와 브라우저 분석 화면을 제작했습니다. 이 폴더는 제작 과정과 일부 화면 구현을 소개하는 **공개용 축약 예제**입니다. 운영 홈페이지의 전체 소스나 Android 앱 소스가 아닙니다.

## 실제 홈페이지에서 구현한 것

- 앱 소개, Google Play 링크, Y Labs 브랜드 및 문의 링크
- ZIP 백업의 거래 JSON을 브라우저 안에서 읽어 월별 손익·보유 원가 비중 표시
- 월별·종목별 상세표, 메모 작성률 등 기록 복기 지표
- 화면 크기에 따라 달라지는 반응형 레이아웃
- 공식 도메인 연결 및 HTTPS 활성화

백업 내용은 현재 웹 구현에서 서버로 전송하지 않습니다. 웹 문서·이미지·외부 라이브러리 다운로드 통신은 발생합니다. 현재 웹에는 계정 로그인·클라우드 동기화·실시간 시세 기능이 없습니다.

## 공개 예제 범위

`demo/`는 가상 JSON에서 월별 손익을 더해 카드와 차트에 표시합니다. **앱의 ZIP 백업과 호환되지 않으며**, 원가·환율·세금 계산 엔진을 재현하지 않습니다. 예제의 `netPnl`은 이미 계산된 가상 순손익입니다. 실제 개인 거래 파일을 사용하지 마세요.

운영 배포 설정, 계정·프로젝트 식별자, 도메인 인증 문자열, API 키, 서명키, 개인 백업, 결제 내역은 포함하지 않았습니다.

## 실행

저장소를 내려받고 이 폴더로 이동한 다음 Python 3로 실행합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory demo
```

Windows에서 `python` 대신 `py` 실행기를 사용하는 경우 `py -m http.server ...`로 실행하세요. 브라우저에서 `http://127.0.0.1:8765/`를 열고 **가상 데이터 보기**를 누릅니다. ES 모듈을 사용하므로 파일을 더블클릭하기보다 로컬 서버로 실행하세요.

Node.js가 있다면 별도 패키지 설치 없이 계산·입력 검증을 테스트할 수 있습니다.

```sh
node tests/summary.test.mjs
```

## 기술과 역할

| 기술 | 실제 홈페이지 | 공개 예제 |
|---|---|---|
| HTML / CSS | 소개 페이지·분석 표·반응형 | 카드·버튼·차트 배치 |
| JavaScript | 파일 읽기·거래 분석·화면 반영 | 입력 검증·월별 합산 |
| Canvas | 월별 손익·보유 비중 | 월별 손익 막대 차트 |
| JSZip | ZIP 파일 읽기 | 사용하지 않음 |
| 정적 호스팅 / DNS | 홈페이지 게시·공식 도메인 연결 | 로컬 실행만 안내 |
